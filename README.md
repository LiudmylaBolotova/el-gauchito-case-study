# Carnicería El Gauchito — Case Study

Commercial website for Carnicería El Gauchito, a local butcher shop in Punta Arenas, Chile.

**Live site:** https://elgauchito.cl

## Project Overview

The goal was to create a modern, fast and useful website for a real local business without turning it into an e-commerce platform.

The site had to help customers understand the business, explore representative products, learn about the origin of the meat, prepare for a visit and discover practical information before coming to the store.

## Asado Calculator

A dedicated calculator helps users estimate how much meat to buy based on the number of adults and children attending an asado.

The calculation logic is separated from the UI and tested independently.

## Business Constraints

The store does not operate as an online shop.

There is no cart, checkout, online ordering or real-time inventory.

The website is intentionally designed to support an offline customer journey and help users prepare before visiting the physical store.
